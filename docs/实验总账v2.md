## 序号1执行口径

- 两边使用相同KITTI数据、随机种子、B8、训练配置和初始模型状态。
- 旧版保留原始普通注意力行为；新版启用`need_weights=False`注意力快速路径。
- 两边各运行真实2个训练轮次，不使用合成微基准代替训练。
- 旧版完整验证使用中央处理器评测器；新版完整验证使用`numba-cuda`图形处理器评测器。
- 另将同一份预测文件分别交给两种评测器，核对AP是否一致，再比较纯AP计算耗时。
- 同时记录PyTorch峰值已分配/保留显存和宿主机可见的进程峰值显存；中央处理器评测记录峰值常驻内存。
- 新旧代码提交、环境版本、命令、日志和结果文件必须在开始前锁定到实验目录。
- 本实验不运行B16，不训练正式250轮基线，不评价检测方法精度优劣。

首次旧版命令在构建模型前导入失败，没有运行训练或产生性能数据。官方包装器把PyTorch 2.4误判为旧版并导入已删除的`_LinearWithBias`私有别名；基准入口只临时恢复该别名及`torch._overrides`兼容名称，不改变旧版`need_weights=True`注意力计算，随后按相同口径执行正确性重跑1。

## 序号1结果明细

| 指标 | 旧版 | 新版 | 新版变化 |
|---|---:|---:|---:|
| 2轮训练总时间（越低越好） | 323.33秒 | **297.12秒** | **-8.11%** |
| 平均训练吞吐（越高越好） | 22.97图/秒 | **25.06图/秒** | **+9.14%** |
| 训练峰值已分配显存（越低越好） | 11.93 GiB | **7.34 GiB** | **-38.44%** |
| 训练峰值已保留显存（越低越好） | 13.78 GiB | **7.66 GiB** | **-44.39%** |
| 3769张验证图的纯模型GPU时间（越低越好） | 38.63秒 | **36.25秒** | **-6.16%** |
| 生成全部预测文件（越低越好） | 54.59秒 | **52.62秒** | **-3.61%** |
| 验证峰值已分配显存（越低越好） | 2.49 GiB | **1.34 GiB** | **-46.05%** |
| AP评测首次运行，含编译/初始化（越低越好） | CPU 5.73秒 | **GPU 5.24秒** | **-8.63%** |
| AP评测预热后平均（越低越好） | CPU 2.57秒 | **GPU 1.57秒** | **-38.82%** |
| 完整验证流程，首次评测（越低越好） | 60.33秒 | **57.63秒** | **-4.47%** |

注意：新旧训练的初始模型SHA256完全一致。新旧预测文件的GPU评测分别为22.4822与22.4980，差-0.0158 AP；这与已知的PyTorch/cuDNN数值路径变化量级一致，本实验不把它解读为模型方法改动。历史CPU回退评测器使用OpenCV旋转矩形相交，而官方GPU路径使用仓库原有的CUDA多边形实现，阈值附近框的差异会改变AP，因此CPU结果只用于记录旧工作流速度。
